## Company Summary

Templ is a **WordPress hosting company** headquartered in Sweden, serving 3,000+ businesses globally. Built on **Google Cloud Platform**, it differentiates on speed (avg. 200% improvement post-migration), security, and unusually hands-on support — including coding, debugging, design, and CSS as paid add-ons.

**Core product:** Per-site cloud WordPress hosting with auto-scaling, Nginx, Redis, MariaDB, Google Cloud CDN, HTTP/3, daily backups, and 24/7 monitoring. Full SSH/WP-CLI access, staging environments, Git support, Node.js and Composer available on all plans.

**Target segments:** SMBs, WooCommerce stores, agencies.

**Revenue model:** Per-site subscription + extended support à la carte ($69–$289/task, $169/hr dev work).

**Data centers:** 34 regions globally (US, EU, APAC, LATAM).
