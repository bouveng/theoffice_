## Platform Notes

### Discord
- All icons work
- Some may appear as emoji (colored)
- Use sparingly for clean look

### Telegram
- Excellent support
- Icons render consistently
- Good for status indicators

### WhatsApp
- Basic icons work
- Complex icons may not render
- Test before sending

### Signal
- Good compatibility
- Consistent rendering
- Ideal for simple icons

## Copy-Paste Ready

Simply copy any icon and paste into your chat application. No special formatting needed.

## Search Tips
- Use **Ctrl+F** to find icons
- Search by: shape (star, arrow, heart)
- Search by: function (check, cross, warning)
- Search by: category (navigation, status, weather)
