## Platform Compatibility

All icons in this reference render as **monochrome text** on:
- ✅ Discord (not colored emoji)
- ✅ Telegram (consistent black/white)
- ✅ Signal (faithful rendering)
- ✅ WhatsApp (basic text)
- ✅ Slack (monochrome symbols)

## When to Use Monochrome Version

1. **Professional communications** - Business, technical, formal
2. **Cross-platform consistency** - Same appearance everywhere
3. **Accessibility** - No color dependency
4. **Code/documentation** - Inline symbols in text
5. **Minimalist design** - Clean, text-only interfaces

## Copy-Paste Ready

Simply copy any icon and paste into your chat application. All icons will display as black/white text, not colored emoji.

## Search Tips
- Use **Ctrl+F** to find icons
- Search by: function (arrow, check, box)
- Search by: category (navigation, math, currency)
- Search by: Unicode range (U+2190 for arrows)
