# Office

Autonomous AI enterprise platform. A decentralized alternative to traditional management, powered by a locally-hosted swarm of frontier-class intelligence.

See [`office.md`](framework/office.md) for architecture and framework documentation.

## Stack

- Language: Python
- Agent framework: Custom (see [research/orchestration.md](research/architecture/orchestration.md))
- Local model runner: Ollama / MLX (Apple Silicon); llama.cpp Metal backend
- Communication layer: MCP (Model Context Protocol)
