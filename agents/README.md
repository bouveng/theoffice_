# Agents

Agent definitions for the [Office](../framework/office.md) swarm. Each agent has a role, identity, and set of responsibilities within the platform. Agents are organized into three tiers based on scope and authority.

## Tiers

- [Management](management/README.md) — Executive-level agents that set strategy and direction
- [Specialists](specialists/README.md) — Domain-expert agents that own specific functions
- [Workers](workers/README.md) — Task-focused agents that execute operational work
